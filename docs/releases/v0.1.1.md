# Freedar v0.1.1

Clearer loading feedback for the map and radar. Requires **Android 8.0 or newer**.

## What's new

- A small, centered falling-raindrops indicator appears when imagery loading takes
  longer than 200 ms, including startup, pan/zoom, and playback-frame preparation.
- Concurrent map and radar loads share one indicator. Cached playback and routine
  background refresh stay quiet; abandoned requests cannot prolong loading feedback.
- Previous radar imagery and its frame time stay visible while replacements load,
  including when navigation interrupts a frame transition.
- Loading feedback respects open panels, backgrounding, both themes, and disabled
  system animations. Failure and retry-countdown information remain available in Info.

## Install or update

Download [freedar-0.1.1.apk](https://github.com/awstephan/freedar/releases/download/v0.1.1/freedar-0.1.1.apk)
and install it over v0.1.0 to retain your settings and cached data. The universal APK
supports ARM and x86 devices. `SHA256SUMS` contains its SHA-256 checksum.

Debug installations use a different signing certificate. See the
[installation instructions](https://github.com/awstephan/freedar#download-and-install)
if switching from a debug build.

## Validation and limitations

The loading changes passed physical-device checks on Pixel 9 Pro XL / Android 17,
including playback, navigation, concurrent loads, panel behavior, and reduced motion.
All 91 JVM test cases and debug lint passed. The full device suite reported 32 passed,
two previously documented failures (large-text control sizing and an outdated offline
status-text assertion), and four opt-in skips. Details are in
[`docs/validation/issue-14.md`](https://github.com/awstephan/freedar/blob/v0.1.1/docs/validation/issue-14.md).

Radar remains historical imagery, not a forecast or warning service. Initial history
loading can be slow under provider request limits. Offline use reuses recently viewed
resources rather than downloading a complete map. This release's loading validation
does not establish performance on older hardware or every live-provider condition.
