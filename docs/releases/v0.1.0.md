# Freedar v0.1.0

The first release of Freedar, a map-first Android precipitation radar viewer.
**Android 8.0 or newer** is required. No Google Play Services, Play Store,
account, or end-user API-key setup is needed. Source code is licensed under
BSD 3-Clause.

## Included

- Worldwide map exploration with light, dark, and system themes.
- Approximately two hours of RainViewer radar history, playback and scrubbing.
- Offline city/town search and one-shot location with map markers.
- Radar freshness and coverage information, opacity and playback-speed controls.
- Bounded on-device reuse of recently viewed map/radar imagery.
- Offline software licenses and third-party notices in Settings → About.

## Install

1. Download [freedar-0.1.0.apk](https://github.com/awstephan/freedar/releases/download/v0.1.0/freedar-0.1.0.apk)
   (approximately 76 MB). One universal APK supports ARM and x86 devices.
2. Open it on your Android device and allow installation from your browser or
   file manager when Android asks.
3. Launch Freedar to explore the map and latest available radar.

An existing debug build uses a different signing certificate: uninstall it before
installing this release. Uninstalling removes its settings and cached data.
For future updates, download a newer signed APK from
[Releases](https://github.com/awstephan/freedar/releases) and install it over this
release to retain your settings. There is no automatic updater.

`SHA256SUMS` contains the APK's SHA-256 checksum.

Release signing, version metadata, the embedded basemap key, bundled license
notices, and the uploaded APK checksum were verified. Source: tag `v0.1.0`,
commit `ab93939`.

Downloads follow repository visibility: while the repository is private, access
is required; once public, the same download links work for everyone.

## Known limitations

- Radar is historical precipitation imagery, not a forecast or warning service.
- First-time history loading can be slow under provider request limits. Offline
  use only reuses recently viewed resources, not a complete downloaded map.
- This release has automated build/unit/lint checks; no new physical-device
  validation is claimed for this release.
