# Freedar v0.1.0

First private APK release of Freedar, a map-first Android precipitation radar
viewer. Android 8.0 or newer is required. No Google Play Services or end-user
provider account is needed.

## Included

- Worldwide map exploration with light, dark, and system themes.
- Approximately two hours of RainViewer radar history, playback and scrubbing.
- Offline city/town search and one-shot location with map markers.
- Radar freshness and coverage information, opacity and playback-speed controls.
- Bounded on-device reuse of recently viewed map/radar imagery.
- Offline software licenses and third-party notices in Settings → About.

## Install

Download `freedar-0.1.0.apk` from this release and open it on your Android device.
Allow installation from your browser or file manager when Android asks.

An existing debug build uses a different signing certificate: uninstall it before
installing this release. Uninstalling removes its settings and cached data.
Future release APKs signed with the same release key can update this installation.

`SHA256SUMS` contains the APK's SHA-256 checksum.

## Known limitations

- This repository and release are private. Downloads and source links require
  repository access; share access through GitHub rather than treating asset URLs
  as public download links.
- Radar is historical precipitation imagery, not a forecast or warning service.
- First-time history loading can be slow under provider request limits. Offline
  use only reuses recently viewed resources, not a complete downloaded map.
- Updates are installed manually; there is no automatic updater.
- This release has automated build/unit/lint checks; no new physical-device
  validation is claimed for this release candidate.
