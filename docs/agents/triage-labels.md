# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs triage | needs-triage | Maintainer evaluation needed |
| Needs information | needs-info | Waiting on reporter |
| Agent ready | ready-for-agent | Fully specified for autonomous work |
| Human ready | ready-for-human | Requires human implementation |
| Won't fix | wontfix | Will not be actioned |

Use these exact label strings when applying triage roles.
